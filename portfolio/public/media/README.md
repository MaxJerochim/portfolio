# Media de los proyectos

Cada carpeta acá adentro es la galería de un proyecto (`proyecto-1`, `proyecto-2`, ...).

Ahora mismo tienen SVGs placeholder (violeta/rojo, con un ícono de play) solo para
que el sitio se vea completo y el lightbox tenga algo para mostrar. Reemplazalos
por tus capturas/fotos reales (`.jpg`, `.png`, `.webp`) y, si tenés, un video
(`demo.mp4`) — después actualizá las rutas en `src/data/projects.js`.

No hay límite de cantidad de imágenes por proyecto: agregá todas las que quieras
al array `gallery` de ese proyecto.
